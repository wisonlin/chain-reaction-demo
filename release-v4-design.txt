# 星渡 v4 / Build 3：声音、反馈与成长

用户授权：2026-10-24 要求改善声音、增加音乐和回血、放大战斗信息、提高火力成长并让难度逐步上升。本次明确授权取代上一版仅改美术的限制；仍为纵向弹幕射击，单指相对拖动、自动攻击、三关顺序和有限次数的大招不变。

## 使用的 Skill 与实际决策

来源仓库 gamedev-skills/awesome-gamedev-agent-skills（检索时 3,205 stars，game-feel 8.7K installs），已安装 audio-design、game-feel、game-ui-ux、level-design。它们提供通用实践，SpriteKit/AVFoundation 执行具体实现。

- audio-design：短音预解码并复用声道、长音乐从文件播放；SFX 与音乐分开开关；重复射击和爆炸有三个样本轮换并限频；大招和受伤时音乐降低约 70%，0.8 秒后恢复。原生所有播放工作留在音频队列。两个完整乐段在首领出现时交叉淡入，暂停/后台暂停音乐。
- game-feel：回血、火力升级、大招采用不同音色、短光环和大文字提示；只有受伤及大招使用较强反馈；反馈不冻结输入、不改变碰撞。
- game-ui-ux：生命 17 pt、火力 20 pt、首领信息 15 pt、大招文字 18 pt；大招 88×88 pt，其余战斗按钮 44×44 pt；适配安全区。血量、火力、大招改变立即推送 HUD，其余动态数值最多 12.5 Hz。iPhone、iPad 均执行实际 UI 测试。
- level-design：前段学习、后段加压；10/25/39 秒有补给窗口，新敌波最少推迟 2.6 秒，已有敌人射击暂时放缓；总体波次间隔、射击频率和弹速随关卡进度增长。

## 数值与可读性

生命维持三格。绿色方框 + 恢复一格，最高三格；满血拾取转为 300 分。回血不恢复火力、不消耗大招；提供 1.2 秒保护。受伤后的补给窗口、运输敌人掉落可出现回血；场上最多一个，两个回血掉落至少间隔 12 秒。

火力从 1 级成长到 6 级，满级后的强化转为 250 分。散射每轮 3/5/7/7/9/11 发，射击间隔随等级缩短；激光在 3 级双路、5 级三路，4/6 级提高贯穿目标数；追踪在 3/5 级增加主弹道、5 级增加到四枚追踪弹。所有职业伤害与主武器形状都随等级提高。

危险敌弹使用深色轮廓、红/橙/金色的圆形或椭圆弹芯；己方攻击是浅蓝白色细长光束；补给为有边框的方牌，↑ 火力、+ 生命、✦ 大招；得分碎片小而金色。颜色与形状同时编码，危险弹仍绘制在立绘与特效之上。

普通敌人耐久随进度适度提高。首领基础生命 1550/2200/2850，困难模式 ×1.12；既有首领二阶段和光柱预警仍保留。每关内弹速与射击频率连续上升；跨关开头及补给有恢复节奏。这是可调的首次平衡，不把机器人通关率等同于人的难度或乐趣。

## 验收与可复现性

`npm test`：95 项，包括回血上限、重复收集、掉落间隔、实物吸附恢复、增长曲线、三职业满级成长、节点预算、六角色两难度原生/网页共享核心一致性。

`npm run check:flight`：18 局固定种子，无附加生命/无敌；9 局通关，所有局六分钟内结算。仅诊断平衡与终态，不代表人的通关率。结果保存 `artifacts/balance/starborne-v4.json`。

`npm run test:native`：iPhone/iPad 各 9 项 XCTest/XCUITest；声音开启的四个 Release 性能场景，其中两个从第三关后段、6 级火力开局进行压力检查，仍可受伤及失败。每场帧间隔 P95 16.7 ms，全部通过既有预算。模拟器不代表真机长时间温控表现。

网页冷启动增加四秒图形初始化超时，驱动无响应时切到 Canvas，避免菜单一直等待。实际 Chrome 390×844 验证了该回退、六角色、启动与战斗大号 HUD。发布前检验公共 HTTPS 文件与本地 SHA256 一致。
