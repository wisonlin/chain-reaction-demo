明确的游玩循环

选择地图或材料目标 → 单指战斗 → 拿到材料与成绩 → 升级指定角色/武器，或调整队伍 → 挑战更高难度。

启动 → 地图大厅；大厅固定五页签：冒险、副本、角色、营地、设置。大厅导航不会进入战场。

第 1 步

启动和大厅

Web 已实现并检查；iOS 待模拟器验收
  • 独立启动画面，明确进入游戏
  • 地图作为默认大厅内容
  • 固定五页签；每页只做一件事
  • 安全区、单手触达、返回路径

验收标准：首次启动先见启动页；进入后看到地图；切换页签不误开战；战斗不显示大厅导航。

第 2 步

角色和编队

Web 已实现并检查；iOS 待模拟器验收
  • 六角色列表和详情
  • 全身展示、等级、星级、武器槽
  • 直接进入对应角色的升级、武器、命座和衣装
  • 独立出战编队确认

验收标准：浏览不改变主战；只有明确选择才改变队伍；换武器和升级能跨重启保留。

第 3 步

冒险和副本

Web 已实现并检查；iOS 待模拟器验收
  • 三张章节地图及解锁条件
  • 三类材料副本与三档难度
  • 出战前显示主要掉落和挑战规则
  • 本机成绩、星级、首次难度解锁
  • 结算后再次挑战和去养成

验收标准：刷取有明确用途；奖励按实际战斗结算一次；重启保留；无体力等待和联网。

第 4 步

战斗辨识和能量

Web 已实现并检查；iOS 待模拟器验收
  • 红橙敌弹、青色己方火力
  • 绿色加号回血、方形火力、金色材料
  • 能量积累与共鸣时间窗
  • 简化HUD、保留清晰判定点

验收标准：形状和颜色都能区分危险与奖励；能量满时有可测量效果；大招依然有限。

第 5 步

技巧和难度

Web 已实现并检查；iOS 待模拟器验收
  • 危险攻击提前预警
  • 瞄准、诱导扇射、穿弹幕空隙和大招时机
  • 难度改变节奏与弹速
  • 可理解的失败与结算评级

验收标准：同配置可通过操作改善结果；不用只堆血量制造难度；普通、困难、极限区别可见。

第 6 步

美术和交付

美术与 Web 已完成；iOS 验收与 TestFlight 待继续
  • imagegen 启动主视觉
  • 六角色飞行姿态精修
  • 小屏轮廓、动作混合与特效控制
  • iPhone/iPad 自动化和开声音Release对照
  • 公开HTTPS试玩和内部TestFlight

验收标准：没有占位按钮；资源随包离线；只发布指定截图与报告；保留失败日志与实测限制。

参考了什么，如何转成自己的设计

  • Archero 2 官方商店介绍：将章节、倒计时生存与奖励副本分开，战斗中的技能选择会改变本局。
  • Sky Force Reloaded 官方商店介绍：关卡任务、难度解锁、机体差异和装备升级，构成重复挑战的理由。

这些是从官方产品介绍推导的设计取舍：让剧情地图、奖励副本和角色配置各有入口；用难度、评级、材料用途和队伍差异形成重复挑战的理由。没有加入体力倒计时、服务器活动或联网依赖。
